## 关于两份 WorkBuddy 报告

两个仓库的 `index.html` 标题完全相同（「WorkBuddy B站传播策略洞察报告」），但**数据窗口不同**：

- `2026-03` 版：数据线索集中在 2026-03-10~12，分析对象以 WorkBuddy 为主
- `2026-08` 版：数据线索集中在 2026-08-17~19，额外涉及 Trae

因此按时间窗口区分命名，不是重复内容。若后续确认某份是冗余版本，可在此说明并删除。
