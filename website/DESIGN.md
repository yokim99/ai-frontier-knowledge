# AI新闻洞察 · 设计说明

- 视觉：浅色、专业、留白充分；标题突出但不要冗长 Hero、分层阅读路径、过多统计与侧边导航。
- 顶部：「AI新闻洞察」「收藏价值新闻，提炼洞见」；不展示无效口号和重复按钮。
- 信息层：直接展示精选文章，类别沿用 AI 洞察日报分类体系，不再拆为“重点 / 主题脉络 / 完整文章”。
- 筛选：全部、个人收藏、日报点赞；相同文章被双渠道收藏则同卡显示两个标签。
- 卡片：文章标题、摘要、日期、来源和原文入口；用户没有明确感想则完全隐藏感想块，不显示“待补充”。
- 附录：仅日报与 GitHub 知识库。
- 数据同步：前端读取统一 JSON 不等于后台自动同步事件。需要单独实现被授权的跨产品数据写入流程。
