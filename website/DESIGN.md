# 网站设计说明

## 视觉命题

像清晨打开的研究笔记：冷白纸面、薄荷绿与浅蓝分区，留白充足，信息密度可控。页面的记忆点是一条真实的“1 → 2 → 3”阅读路径。

## 内容计划

1. 重点阅读：先给出优先级，降低选择成本。
2. 主题脉络：把文章归入商业与模型、Agent 与产品、增长与治理三条主线。
3. 完整文章：保留标题、摘要、用户感想状态和原始链接。
4. 附录：集中放日报全集、主题聚合与 GitHub 知识库。

## 交互命题

- 顶部阅读进度条告诉用户当前所在位置。
- 主题脉络可以一键过滤完整文章，并自动进入证据层。
- 搜索、来源筛选和清空筛选始终给出明确结果数量。

## 内容边界

“我的感想”只记录用户明确表达的收藏动作、点赞行为或原话。没有具体感想时显示“待补充”，不以编辑分析代替用户观点。
