## 使用方式

1. **浏览分析笔记**: 直接进入 `文章分析/` 目录查看已整理的分析
2. **贡献内容**: 欢迎提交 Pull Request 分享你发现的优质 AI 文章和分析
3. **建议格式**: 每篇文章分析包含：核心概要、关键事件时间线、技术/商业分析、关键洞察与思考

## 关注方向

- **AI Agent**: Agent协议（A2A/MCP/ACP）、GUI Agent、多Agent协作
- **大模型**: 模型架构、训练方法、推理优化、多模态
- **AI产品**: 产品形态、商业模式、用户增长、生态建设
- **AI基础设施**: 算力、数据、工具链、开发框架
- **AI治理**: 安全、隐私、伦理、政策法规
