# 来源地图：先发现，再追到原始证据

| 领域 | 优先查找的原始材料 |
|---|---|
| 政策与会议 | 政府官网正式文件、监管机构原文、主办方会议议程与演讲全文 |
| 行业研究/商业化 | Gartner 等研究机构正式摘要/报告方法说明、企业财报/申报文件与原始表格 |
| 论文与技术 | 论文正文、数据与代码、基准数据集、第三方复现；明确作者与第三方结论边界 |
| IaaS/算力 | 芯片及集群厂商技术规格、云供应商产品公告、真实交付状态 |
| 模型/模型服务 | 模型卡、系统卡、API文档、定价表、上下文上限、使用条款、发布版本 |
| PaaS/Agent平台 | 模型服务/Agent开发平台官方日志、SDK文档、权限与工作流说明 |
| SaaS Agent | Coding/Working/Personal Agent 产品更新日志、帮助文档、公开定价与用户案例 |
| AI硬件 | 厂商正式发布、规格及适用范围、独立实测与真实用户反馈 |
| 产品/运营 | 官方活动细则、产品漏斗公开指标、独立调查、渠道与生命周期运营机制 |

发现线索的辅助源：Product Hunt 榜单（注意采集时间和榜单口径）、媒体报道、科技社区、用户评论。**辅助源不能替代原始来源**。

按重要性选择，不追求全部领域每天都有条目。

重点领域可逐项检查：
- **Coding Agent**：任务级/项目级代码理解、自动执行与工具调用、IDE与代码仓库、PR review、沙箱与权限、成功率与成本。
- **Working Agent**：跨应用任务、办公数据读写、授权与审批、计划/定时任务、结果交付与审查。
- **Personal Agent**：主动提醒、长期记忆、信息与隐私治理、移动/多端任务。
- **其他赛道**：出现可验证的新方向可列为观察，但不擅自声明用户已决定长期监控。

对历史资料保存原始发布日期、产品/端/地区/套餐范围与“当时能否使用”。
